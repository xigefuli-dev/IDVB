# 置信度重构验证报告

## 📊 基线数据分析

**数据来源**: AlignmentResearch 历史记录（重构前收集）  
**样本数量**: 1025 次对齐尝试  
**时间范围**: 2026-08-01 至 2026-08-02

### 重构前通过率

```
总尝试次数: 1025
  ✓ 接受: 750 (73.17%)
  ✗ 拒绝: 275 (26.83%)

置信度分布:
  高置信度 (82%+): 103 (10.0%)
  中等置信度 (62-82%): 625 (61.0%)
  低置信度 (<62%): 297 (29.0%)
```

**结论**: 重构前的总体通过率为 **73.17%**，远低于 95% 的目标。

## 🔧 重构内容

### 核心改进

1. **双门对齐**: 70:30 权重（门分数:几何）→ 高门分数更容易达到阈值
2. **单门跟踪**: 75% 当前观测 + 15% 基线 + 10% 尺度
3. **侧门扫描**: 原生支持地图ID先验，避免外部拼接
4. **结构配准**: 内部融合侧门先验，根据场景调整权重

### 预期效果

基于重构逻辑和单元测试：
- 双门对齐: 清晰门(0.887) + 容差内几何 → 75% 置信度（之前难以达到62%）
- 单门跟踪: 高质量门(0.90) → 87% 置信度（提升7%）
- 侧门定位: 先验(0.85) + 位置(0.65) → 72% 置信度（更自然）
